# 长链接对比

http 长连接 vs http stream 长连接 vs http sre 长连接 vs ws 长连接 vs http2 长连接 vs tcp 长连接

| 特性/协议            | HTTP 长连接             | HTTP Stream 长连接                     | HTTP SSE 长连接                                                    | WebSocket 长连接                                      | HTTP/2 长连接                                                                                                            | TCP 长连接   |
| -------------------- | ----------------------- | -------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------ |
| **协议层**           | 应用层                  | 应用层                                 | 应用层                                                             | 应用层                                                | 应用层                                                                                                                   | 传输层       |
| **连接类型**         | 单向（客户端 → 服务器） | 单向（服务器 → 客户端）                | 单向（服务器 → 客户端）                                            | 全双工                                                | 半双工<br />客户端发起的请求，必须使用的是奇数号 Stream，<br />服务器主动的推送，使用的是偶数号 Stream<br />可以并发进行 | 全双工       |
| **数据格式**         | 文本                    | 文本                                   | 文本                                                               | 二进制/文本                                           | 文本                                                                                                                     | 任意         |
| **是否支持多路复用** | 否                      | 否                                     | 否                                                                 | 否                                                    | 是                                                                                                                       | 否           |
| **适用场景**         | 网页浏览                | 实时数据流，<br />如视频，音频，日志流 | 实时事件推送：<br />股票行情，<br />新闻广播，<br />大模型结果推送 | 实时双向通信：IM 实时通信<br />QQ、在线游戏、协同编辑 | 现代 Web 应用：<br />隧道通信                                                                                            | 长期数据交换 |
