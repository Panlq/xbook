# 知识点杂记

# [断网了，还能 ping 通 127.0.0.1 吗？](https://www.xiaolincoding.com/network/4_ip/ping_lo.html#%E4%BB%80%E4%B9%88%E6%98%AF127-0-0-1)

> 答：能 ping 通，127.0.0.1 是一个本地回环地址，发起 ping 命令后，通过 lo0 回环网卡走一圈就兜回来了。内核规定 127.0.0.1 是一个 local 的地址，当发现目标 IP 是回环地址/本地 IP 时，选择走本地网卡，如果是外网 IP，才会走真网卡(网线)。
>
> 本地回环的数据会被推入一个叫 `input_pkt_queue` 的链表中，这个链表，其实是所有网卡共享的，上面挂着发给本机的各种消息。消息被发送到这个链表后，会再触发一个软中断。有一个内核线程 ksoftirqd 专门处理软中断的工具人，它在收到软中断后就会立马去链表里把消息取出，然后顺着数据链路层、网络层等层层往上传递最后给到应用程序。
>
> **ping 回环地址和通过 TCP 等各种协议发送数据到回环地址都是走这条路径**

回环地址：lo0，127.0.0.1

**ping 回环地址(lo0「127.0.0.1」))和 ping 本机地址(192.168.31.6)没有区别** 。

## 127.0.0.1 和 localhost 以及 0.0.0.0 有区别吗

1. localhost 不是 IP，是一个域名，只不过默认解析到 127.0.0.1 (`/etc/hosts`中可以配置)
2. **0.0.0.0：这是一个通配符地址（wildcard address），表示“所有可用的 IPv4 地址”。当服务绑定到 `0.0.0.0` 时，它可以接受来自任何网络接口的连接请求（包括局域网、公网等）**

### 一、`127.0.0.1`

- **定义**：这是本地回环地址（loopback address）。
- **作用** ：用于本机访问自己的网络服务。也就是说，当你在本机使用 `127.0.0.1` 去访问某个服务时，数据不会经过物理网络接口，而是直接返回本机。

### 二、`localhost`

- **定义** ：这是一个主机名（hostname），通常被解析为 `127.0.0.1`。
- **作用** ：和 `127.0.0.1` 类似，也是用于本机访问自己。
- **区别** ：
- `localhost` 是一个域名，需要 DNS 或 hosts 文件解析，默认解析为 `127.0.0.1`（IPv4）或 `::1`（IPv6）。
- 在某些系统中，比如 Windows 或 Linux，`localhost` 可能优先使用 IPv6（即 `::1`），而 `127.0.0.1` 明确是 IPv4。

### 三、`0.0.0.0`

- **定义** ：这是一个通配符地址（wildcard address）。
- **作用** ：表示“所有可用的 IPv4 地址”。当服务绑定到 `0.0.0.0` 时，它可以接受来自任何网络接口的连接请求（包括局域网、公网等）。
- **应用场景** ：
- 如果你在本机运行一个 Web 服务器，并希望局域网中的其他设备也能访问它，你需要让它监听 `0.0.0.0:80` 而不是 `127.0.0.1:80`
- 默认情况下，很多服务只监听 `127.0.0.1`，这意味着只能从本机访问，外部无法访问。
- **注意** ：`0.0.0.0` 不是一个可以 ping 通的地址，它只是一个占位符，表示“任意地址”。

```bash
/* Address to accept any incoming messages. */
#define    INADDR_ANY      ((unsigned long int) 0x00000000) /* 0.0.0.0   */
```

### 总结对比

| 地址        | 含义                         | 是否可配置 | 是否能被外部访问 | 使用场景                    |
| ----------- | ---------------------------- | ---------- | ---------------- | --------------------------- |
| `127.0.0.1` | 回环地址（IPv4）             | 否         | 否               | 本机测试服务                |
| `localhost` | 主机名，默认解析为 127.0.0.1 | 是（可改） | 否               | 本机测试服务，可能支持 IPv6 |
| `0.0.0.0`   | 所有 IPv4 地址               | 否         | 是               | 让服务对外部开放访问        |

#### Q: 为什么有时候用 `localhost` 比 `127.0.0.1` 更慢？

A：因为 `localhost` 需要进行 DNS 解析（尽管通常是本地 hosts 文件），有时会触发 IPv6 尝试连接，如果应用不支持 IPv6，会导致延迟。
