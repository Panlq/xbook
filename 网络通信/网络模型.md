### OSI 七层网络模型功能：

| 层次       | 功能                                                                           | 设备               | 协议                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 物理层     | 比特传输                                                                       | 集线器、网线、光纤 | RS-232、RJ-45、IEEE 802.3                                                                                                              |
| 数据链路层 | 帧传输与差错控制                                                               | 交换机、网桥、网卡 | PPP、HDLC、MAC、ARP                                                                                                                    |
| 网络层     | 路由与逻辑寻址                                                                 | 路由器             | IP（IPv4、IPv6）、ICMP（互联网控制消息协议）、<br />IGMP（互联网组管理协议）、OSPF（开放最短路径优先）                                 |
| 传输层     | 提供端到端的可靠或不可靠数据传输，<br />具有流量控制、错误检测、多路复用等功能 | 软件实现           | TCP、UDP、SCTP                                                                                                                         |
| 会话层     | 会话管理                                                                       | 软件实现           | NetBIOS、RPC、SQL、NFS                                                                                                                 |
| 表示层     | 负责数据的语法转换、加密、压缩等，<br />确保不同系统之间可以理解彼此的数据格式 | 软件实现           | SSL/TLS（安全套接字层 / 传输层安全）、<br />JPEG、MPEG、ASCII、EBCDIC                                                                  |
| 应用层     | 用户接口与服务                                                                 | 终端设备           | HTTP（超文本传输协议）、FTP（文件传输协议）、<br />SMTP（简单邮件传输协议）、DNS（域名系统）、<br />Telnet（远程登录协议）、POP3、IMAP |

以上是 OSI 七层模型中各层的基本功能、相关设备及其常见协议
