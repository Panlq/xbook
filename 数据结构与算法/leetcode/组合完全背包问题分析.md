# 组合完全背包问题

对应 leetcode 题目 [518. 零钱兑换 II](https://leetcode.cn/problems/coin-change-ii/)

# 1. 问题定义

- **物品** ：`weights = [1, 2, 5]`（可重复使用）
- **背包容量** ：5
- **目标** ：计算放满背包的组合数（顺序无关）

# 2. 二维 DP 数组定义

定义二维数组 `dp`：

- `dp[i][j]`：使用前 `i`个物品（可重复使用）放满容量 `j`的方案数
- `i`范围：`0`到 `n`（`n`为物品数量）
- `j`范围：`0`到 `capacity`

## 1. 初始化

```python
dp = [[0]*(capacity+1) for _ in range(n+1)]
dp[0][0] = 1  # 容量0有1种方案（不放物品）
```

初始状态：

- 使用 0 个物品时：
  - 只能凑出容量 0（`dp[0][0] = 1`）
  - 其他 `dp[0][j>0] = 0`

## 2. 递推公式的演进

> dp[i][j] = dp[i-1][j] + dp[i][j-weight]

**物理意义** ：

1. `dp[i-1][j]`：完全不选当前物品 `i`的方案数
2. `dp[i][j-weight]`：**选至少一个**物品 `i`后，用前 `i`个物品（含 `i`）凑剩余容量 `j-weight`的方案数

## 3. 完整 DP 表格（capacity=5）

| 物品\容量        | 0   | 1   | 2   | 3   | 4   | 5   |
| ---------------- | --- | --- | --- | --- | --- | --- |
| 物品 0           | 1   | 0   | 0   | 0   | 0   | 0   |
| 物品 1（重量 1） | 1   | 1   | 1   | 1   | 1   | 1   |
| 物品 2（重量 2） | 1   | 1   | 2   | 2   | 3   | 3   |
| 物品 3（重量 5） | 1   | 1   | 2   | 2   | 3   | 4   |

## 4. 实例演算 dp[2][4]=3 的完整过程

1. **初始化** ：

- `dp[0][0] = 1`（容量 0 有 1 种方案：不放物品）
- 其他 `dp[0][j>0] = 0`（无物品时无法凑正容量）

1. **处理物品 1（重量 1）** ：

- `dp[1][j] = dp[0][j] + dp[1][j-1]`
- 例如 `dp[1][4] = 0 + dp[1][3] = ... = 1`（只有 1+1+1+1）

1. **处理物品 2（重量 2）** ：

- 计算 `dp[2][4]`：
  - 不选 2：`dp[1][4] = 1`（1+1+1+1）
  - 选至少一个 2：
    - 放入一个 2，剩余容量=2，
    - `dp[2][2]`：
      - 不选 2：`dp[1][2] = 1`（1+1）
      - 选 2：`dp[2][0] = 1`（放一个 2 后剩余 0）
      - 所以 `dp[2][2] = 1 + 1 = 2`（即 2 或 1+1）
  - 因此选 2 的方案对应：
    - 2 + (2) → 2+2
    - 2 + (1+1) → 2+1+1
- 最终 `dp[2][4] = 1 + 2 = 3`

---

## 5. 为什么这样设计？

完全背包的递推公式设计体现了 **动态规划的最优子结构** ：

- 当决定"至少选一个当前物品"时，剩余容量的问题 **仍然是原问题的子问题** （依然可以用当前物品）
- 如果用 `dp[i-1][j-weight]`，就变成了"恰好选一个当前物品"，漏掉了选多个的情况

## 6. 遍历顺序

```python
for i in range(1, n+1):          # 先遍历物品
    weight = weights[i-1]
    for j in range(capacity+1):  # 再遍历容量
        if j >= weight:
            dp[i][j] = dp[i-1][j] + dp[i][j-weight]
        else:
            dp[i][j] = dp[i-1][j]
```

**顺序重要性** ：

- 必须先物品后容量（组合数问题）
- 计算 `dp[i][j]`时需要 `dp[i][j-weight]`（同一行的左侧值）

## 7. 完整代码实现

```python
def count_combinations_2d(capacity, weights):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    dp[0][0] = 1  # 基础情况

    for i in range(1, n + 1):
        weight = weights[i-1]
        for j in range(capacity + 1):
            # 不选当前物品
            dp[i][j] = dp[i-1][j]
            # 选至少一个当前物品（如果能放下）
            if j >= weight:
                dp[i][j] += dp[i][j - weight]
    return dp[n][capacity]

print(count_combinations_2d(4, [1, 2]))  # 输出3
```

## 8. 完全背包 vs 0-1 背包 递推公式对比

| 背包类型     | 递推公式                                    | 物理意义                       |
| ------------ | ------------------------------------------- | ------------------------------ |
| **0-1 背包** | `dp[i][j] = dp[i-1][j] + dp[i-1][j-weight]` | 物品只能选或不选，选后不能再用 |
| **完全背包** | `dp[i][j] = dp[i-1][j] + dp[i][j-weight]`   | 选了当前物品后，仍然可以再选   |

# 3. 一维 DP 优化原理

> dp[j] = d[j] + dp[j-weight)

dp[j]含义》容量为 j 的背包，放满物品可以有 dp[j]种方法

**等价性** ：

- 外层循环的每次迭代相当于二维 DP 的一行
- 正序更新确保 `dp[j-weight]`是当前行的值（即 `dp[i][j-weight]`）

## 完整代实现

```python
def count_combinations(capacity, weights):
    dp = [0] * (capacity + 1)
    dp[0] = 1
    for weight in weights:
        for j in range(weight, capacity + 1):
            dp[j] += dp[j - weight]
    return dp[capacity]

print(count_combinations(5, [1, 2, 5]))  # 输出4
```
